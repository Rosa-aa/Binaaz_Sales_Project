# 🏠 Bina.az Real Estate Analysis & Price Prediction

## 📌 Overview

This project analyzes real estate listings from bina.az and builds machine learning models to predict property prices in Baku.

## 📊 Key Features

* Data cleaning & preprocessing
* Feature engineering & encoding
* Exploratory Data Analysis (EDA)
* Interactive dashboard
* Machine Learning modeling

## 📈 Insights

* Price does not increase linearly with area
* Certain locations have significantly higher median prices
* Floor level has non-linear impact on price
